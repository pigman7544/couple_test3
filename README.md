# 우리 둘의 이야기 v6.4 — 이야기 중심 리포트 테스트

기존 v6.3 배포 방식 그대로 Render Blueprint를 사용하세요.

- 무료: 커플 결과, 이야기 맛보기, **흐릿한 유료 내용 미리보기**
- 버튼: 5,000원 결제 버튼을 누르면 **실제 결제 없이** 전체 리포트 즉시 열람
- 유료: 문학 이야기 → 인물과 사주 연결 → 두 사주의 관계 → 갈등과 결말 → 현실 장면 → 다른 결말을 쓰는 법
- 사주 이론 장황한 설명과 별자리 방법론 특별 챕터 제거; 태양궁은 인물 해석에 통합
- 백소정·허선(c06)은 전용 서사; 다른 11쌍은 **개별 작품 서사·캐릭터 근거가 아직 충분하지 않은 시제품**
- 실제 결제 기능 없음. 정식 출시 전 서버 결제 검증 및 작품별 콘텐츠 보강 필요.

`pip install -r requirements.txt` 후 `python server.py`로 실행.
